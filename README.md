## Запуск тестів (Лабораторна 2)

Для запуску модульних тестів проєкту (`pytest`) необхідно налаштувати віртуальне середовище Python:

1. **Створення та активація середовища:**
   Відкрийте термінал у корені проєкту та виконайте:
   ```bash
   python -m venv venv
2. **Активація (для Windows):**
   .\venv\Scripts\activate
   (Якщо виникає помилка виконання скриптів, виконайте:
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser)
3. **Встановлення залежностей:**
   Після появи префікса (venv) встановіть фреймворк:
   pip install pytest
4. **Запуск модульних тестів:**
   Для перевірки доменного ядра, інваріантів та репозиторію виконайте:
   python -m pytest tests/
   Очікуваний результат: Усі 6 тестів мають пройти успішно (green build).
